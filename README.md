# Atlas Utòpic v0.67.13

## Novetats
- Fitxes de les tres dimensions amb denominacions definides a partir de les prioritats observades.
- Els perfils compostos es descriuen sense utilitzar una categoria oberta com a resposta comodí.
- Evidència directa: les fitxes mostren respostes seleccionades que sostenen la interpretació.
- Síntesi filosòfica transversal ampliada en quatre apartats: arquitectura de criteris, connexions entre dimensions, manera d'organitzar el pensament i lectura precisa de tensions.
- Preguntes de reflexió construïdes a partir de les prioritats més destacades.
- Es conserva l'estructura de GitHub Pages i els recursos de la versió anterior.

## Publicació
Descomprimeix el paquet i publica `index.html` a GitHub Pages amb els dos icones i el manifest inclosos.

## Nota metodològica
Les denominacions compostes són descripcions analítiques basades en les respostes, no noms de doctrines històriques. Una etiqueta doctrinal és una aproximació comparativa i no implica que la persona subscrigui totes les tesis d'una escola.
